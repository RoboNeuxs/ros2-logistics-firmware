# 仓库初始化说明与使用方法

日期：2026-10-24。仓库：`RoboNeuxs/ros2-logistics-firmware`。可见性：Private。分支：`main`。

## 本步完成内容

建立 README、文档索引、步骤教程模板和 Issue/PR 模板。职责：MCU 外设、编码器、四轮闭环和停车保护。

## 获取项目

运行位置：Windows PowerShell，在你选定的本地开发父目录运行：

```powershell
# 先在 GitHub 将本模块 Fork 到个人账号，再将 YOUR_USERNAME 替换为本人用户名
git clone https://github.com/YOUR_USERNAME/ros2-logistics-firmware.git
cd ros2-logistics-firmware
git remote add upstream https://github.com/RoboNeuxs/ros2-logistics-firmware.git
git status --short --branch
```

`git clone` 下载本仓库；`cd` 进入仓库；`git status` 查看分支和修改。预期为 `main`，首次下载后工作区无修改。私有仓库需使用已获授权的 GitHub 账号。

开发时在个人 Fork 创建功能分支，日常 push 到 `origin`，完成后向组织本仓库发起 PR。详细命令见[个人 Fork 开发与 PR 提交流程](../COLLABORATION.md)。

## 开展任务

进入仓库 Issues，确认模块目标、输入依赖和验收条件，再创建具体任务。按 `docs/templates/步骤完成说明与使用教程.md` 编写操作与验证记录，通过 PR 交付成果并更新 `docs/README.md`。
