## 复现命令与结果

运行环境：Windows PowerShell、Keil µVision5 / Arm Compiler 6.22、Python 3.13.9、pyserial 3.5。默认 Keil 安装目录为 `D:\Application\Keil5`；其他位置通过 `-KeilRoot` 指定。VS Code 代码提示的编译器路径也应按本机安装位置调整。

从仓库根目录执行：

```powershell
cd STM32
powershell -NoProfile -ExecutionPolicy Bypass -File Scripts/build_keil.ps1 -Rebuild
python -B -m unittest discover -s Tests -p test_host.py -v
python -B -m unittest discover -s Tests -p test_gui.py -v
```

`-Rebuild` 表示全量重建；构建脚本会先保存旧 HEX/BIN，再构建、生成 BIN 并运行 `verify_image.py`。`-B` 避免生成 Python 字节码缓存。界面测试需可用的 Tk 图形会话，会短暂创建测试窗口；不需要连接串口设备。

## 使用与版本保存

按 [操作手册](../STM32/README.md) 核对板卡、接线和电平，再编译烧录、安装 `Host/requirements.txt` 并运行 `Host/motor_gui.py`。USART2 使用 PA2/PA3、115200 8N1；BIN 下载起始地址为 `0x08000000`。CPR 默认值只是占位，首次调试车轮悬空，先确认单路低 PWM 和反馈方向，再调闭环。

本次构建已将原 HEX/BIN 保存到本地 `STM32/Build/History/20261026T095857319Z/`，附 `SHA256SUMS.txt`；原有其他构建产物也保留。后续每次构建会另建时间戳目录。GitHub 中的源码可重新构建，旧烧录文件需随本地备份一并保存。
