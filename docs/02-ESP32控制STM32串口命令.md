# ESP32 → STM32 串口指令集合（V4.3）

串口：**115200、8N1、3.3V TTL**。下列 HEX 内容按原始字节发送，不附加换行。

## 帧格式

```text
AA 55 | cmd | seq | v0(2字节) | v1(2字节) | v2(2字节) | v3(2字节) | flags | CRC
```

共 14 字节，多字节值小端；运动目标为 int16，参数写入值为 uint16。CRC-8/SMBUS：poly=0x07、init=0、不反射、xorout=0，计算字节 2～12。修改序号或参数后重新计算 CRC。

## 指令集合

| 功能码 | 功能 | v0、v1、v2、v3 | flags / 条件 |
|---|---|---|---|
| `0x13` | 立即停止全部 | `0, 0, 0, 0` | 0；不自动清故障 |
| `0x14` | 查询状态 | `0, 0, 0, 0` | 0；不续期心跳 |
| `0x15` | 清零编码器累计计数 | `0, 0, 0, 0` | 0=全部，1～4=单台；所选电机模式和实际 PWM 均须停止 |
| `0x16` | 单台或全部使用相同模式、相同目标 | `模式, 目标, 0, 0` | 0=全部，1～4=M1～M4 |
| `0x17` | 四台分别设置模式、目标 | `M1目标, M2目标, M3目标, M4目标` | 每两位表示一台电机模式 |
| `0x18` | 心跳 | `0, 0, 0, 0` | 0；续期已接受的全部运动目标，故障时拒绝 |
| `0x19` | 清除故障 | `0, 0, 0, 0` | 0；必须全部停止；不恢复旧运动目标 |
| `0x20` | 读取参数 | `参数ID, 0, 0, 0` | 电机参数必须选 1～4；全局参数用 0 |
| `0x21` | 写入 RAM 参数 | `参数ID, uint16值, 0, 0` | 电机参数 1～4=单台、0=四台；全局用 0；必须全部停止 |
| `0x23` | 恢复默认 RAM 参数 | `0, 0, 0, 0` | 0；必须全部停止 |

模式：`0=立即停止`、`1=PWM（千分比，±1000）`、`2=速度（count/s，±10000）`、`3=减速停止`。模式 0/3 的目标必须为 0；实际目标受各电机参数上限限制。

`0x17` 的 flags：`M1模式 | (M2模式<<2) | (M3模式<<4) | (M4模式<<6)`；四台 PWM=`0x55`，四台速度=`0xAA`，四台减速停止=`0xFF`。

参数 ID、范围和默认值见 [参数表](../STM32/docs/protocol.md#参数表)；参数写入仅保存在 RAM，掉电恢复默认。

## 完整 HEX 示例

| 指令 | 完整发送帧（含示例序号和 CRC） |
|---|---|
| 通信检查 PING | `50 49 4E 47`（回复 `50 4F 4E 47 0D 0A`） |
| 查询状态 | `AA 55 14 01 00 00 00 00 00 00 00 00 00 E3` |
| 立即停止全部 | `AA 55 13 02 00 00 00 00 00 00 00 00 00 06` |
| M1 PWM +200 | `AA 55 16 03 01 00 C8 00 00 00 00 00 01 56` |
| M1 PWM -200 | `AA 55 16 04 01 00 38 FF 00 00 00 00 01 5B` |
| M1 立即停止 | `AA 55 16 05 00 00 00 00 00 00 00 00 01 7D` |
| 全部减速停止 | `AA 55 16 06 03 00 00 00 00 00 00 00 00 49` |
| M1 速度 +500 count/s | `AA 55 16 07 02 00 F4 01 00 00 00 00 01 BE` |
| 四台均 PWM +200 | `AA 55 17 08 C8 00 C8 00 C8 00 C8 00 55 1F` |
| 四台混合 PWM/速度/停/PWM | `AA 55 17 09 C8 00 F4 01 00 00 38 FF 49 1A` |
| 心跳 | `AA 55 18 0A 00 00 00 00 00 00 00 00 00 96` |
| 清除故障 | `AA 55 19 0B 00 00 00 00 00 00 00 00 00 E1` |
| 全部编码器计数清零 | `AA 55 15 0C 00 00 00 00 00 00 00 00 00 7A` |
| 读取 M1 CPR | `AA 55 20 0D 03 00 00 00 00 00 00 00 01 E3` |
| 设置 M1 CPR=1560（示例） | `AA 55 21 0E 03 00 18 06 00 00 00 00 01 8B` |
| 设置 M1 CPR=60000（编码示例） | `AA 55 21 0F 03 00 60 EA 00 00 00 00 01 74` |
| 设置全局失联超时=1000 ms | `AA 55 21 10 80 00 E8 03 00 00 00 00 00 AF` |
| 恢复默认参数 | `AA 55 23 11 00 00 00 00 00 00 00 00 00 32` |

CPR 数值仅为编码示例，按实际电机填写。默认 1000 ms 失联停车；运动期间持续发送 `0x18` 心跳，PING 和查询不续期。故障恢复：`0x13` 停止 → 排查 → `0x19` 清故障 → 重新发送目标。

二进制应答固定 64 字节，帧头 `AA 55 93`，序号与请求一致；每次等待匹配应答后再发下一条。完整应答格式见 [V4 协议](../STM32/docs/protocol.md#状态帧64-字节)。
