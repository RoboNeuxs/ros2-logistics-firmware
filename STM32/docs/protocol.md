# 四电机串口协议 V4

USART2：PA2=TX、PA3=RX，115200、8N1、无流控，3.3V TTL。多字节在线数据为小端。CRC-8/SMBUS：poly=0x07、init=0、无反射、xorout=0。STM32 V4.3 固件使用配套 Host/motor_host.py；本项目使用自己的帧格式。

## V4 文本 PING

发送 ASCII `PING`（大小写均可），返回 `PONG\r\n`。HEX 模式发送 `50 49 4E 47`，回复为 `50 4F 4E 47 0D 0A`。PING 不启动电机、不清故障、不续期运动心跳。只在二进制帧之外识别文本；连续 100 ms 以上没有新数据时，丢弃未完成的输入帧。

本版固件版本字段为 `0x0403`，参数格式为 4；必须使用配套 V4 上位机。V3 的 11、12、1A、22 指令及参数 129 已移除。Python 的 pwm/speed 接口转为 17 混合控制，info 转为 14 查询。

## 命令帧：14 字节

| 字节 | 内容 |
|---|---|
| 0～1 | AA 55 |
| 2 | 功能码 |
| 3 | 请求序号 0～255 |
| 4～11 | 四个 16 位值 v0、v1、v2、v3 |
| 12 | flags：电机选择器或四台模式 |
| 13 | CRC：计算字节 2～12 |

运动目标为 int16，参数写入值 v1 按 uint16 位模式解释，因此每圈计数可超过 32767。保留值必须为 0。

| 功能码（十六进制） | 功能 | 四个值 | flags |
|---|---|---|---|
| 13 | 立即停止全部 | 全 0 | 0 |
| 14 | 查询状态 | 全 0 | 0 |
| 15 | 清零计数 | 全 0 | 0=全部，1～4=单台 |
| 16 | 设置单台/全部同一模式 | v0=模式，v1=目标，v2/v3=0 | 0=全部，1～4=单台 |
| 17 | 四台混合模式同步设置 | M1～M4 目标 | 每两位分别为 M1～M4 模式 |
| 18 | 心跳 | 全 0 | 0 |
| 19 | 清除故障 | 全 0 | 0；必须全部停止 |
| 20 | 读取参数 | v0=参数 ID，其他 0 | 1～4=电机，全局参数用 0 |
| 21 | 设置参数到 RAM | v0=参数 ID，v1=uint16 值，其他 0 | 0=四台同时设置，1～4=单台；全局用 0 |
| 23 | 恢复默认到 RAM | 全 0 | 0；必须全部停止 |

模式：0=立即停止、1=PWM、2=速度、3=减速停止。模式 0/3 的目标必须为 0。混合模式 flags：M1 占 bit0～1，M2 占 bit2～3，M3 占 bit4～5，M4 占 bit6～7。例如 PWM/速度/停止/PWM 对应 0x49。

单台立即停止和 13 命令立即置零 PWM；17 的四台目标与模式在下一个 50 ms 控制周期一起应用。应答表示指令已接受，实际 PWM 通过状态字段确认。四台请求全部验证通过后才会更新，任何一台越界不会部分执行。

有效运动命令和 18 心跳重置整块板的失联计时。查询、参数命令和无效运动指令不续期。心跳续期当前已接受的所有电机目标，不重发运动目标，也不解除故障。上位机应连续发送心跳；串口只有一个请求发送者，等待匹配应答后再发下一条。

停止不会自动清故障。故障锁存后先 13 停止，再 19 清除，最后由操作者重新发运动命令。单台/全部计数清零要求所选电机的模式和实际 PWM 均停止；实际机械也应静止。

GUI 的立即/减速停止会使此前尚未执行、涉及所选电机的运动请求失效；旧混合请求整条取消，不拆分，也不改写其他电机已生效的目标。读取/应用/恢复参数会先停止全部并取消旧运动请求。停止后新提交的运动请求仍可执行；已经进入串口发送的请求不可撤回，停止等待当前串口操作结束或超时，不是独立硬件急停。

## 状态帧：64 字节

命令应答 type=0x93。固件只按请求返回状态，上位机每 100 ms 查询；不再主动定时上报。

| 字节 | 内容 |
|---|---|
| 0～1 | AA 55 |
| 2 | 93=应答 |
| 3 | 应答的请求序号 |
| 4 | 错误码 |
| 5 | 全局故障位 |
| 6 | 堵转/无反馈电机位图：bit0～3 对应 M1～M4 |
| 7 | bit0=方向推定；bit4～7=参数格式版本，当前 4 |
| 8～9 | 有效控制/心跳指令年龄，uint16 ms，饱和到 65535 |
| 10～20 | M1 状态块 |
| 21～31 | M2 状态块 |
| 32～42 | M3 状态块 |
| 43～53 | M4 状态块 |
| 54～55 | 参数读写的 uint16 值；其他应答忽略 |
| 56 | 参数 ID；仅参数应答有意义 |
| 57 | 参数作用域；仅参数应答有意义 |
| 58～59 | 固件版本 uint16，当前 0x0403=STM32 V4.3 |
| 60～61 | 能力位图，正常固件当前 0x073F |
| 62 | 参数状态：0=默认，2=RAM 已修改；掉电恢复默认 |
| 63 | CRC：计算字节 2～62 |

每台状态块 11 字节：模式 u8、目标 int16、施加的 PWM 千分比指令 int16、速度 int16、累计计数 int32。速度为 count/s，累计计数按 32 位回绕。STM32 V4.3 方向来自 A/B x1 解码。四路 PWM 由 TIM1 产生，20 kHz、每周期 3600 个定时器计数；千分比命令按此分辨率量化，支持 0% 和 100%。

能力位 bit0～11：PWM、速度闭环、单台控制、混合模式同步、减速停止、参数访问、片内保存、自动报告、故障电机位图、计数清零、失联保护、方向推定。当前 bit6/bit7/bit11 清零：不保存到 Flash、不主动报告、方向由 A/B 实测而非推定。

故障位：1=失联，2=接收溢出或 UART 接收错误，4=堵转/无反馈或输入捕获过捕获，8=控制调度超时。任一故障直接清 TIM1 MOE，使四路 PWM 低电平并停止全部电机。STBY 固定高，因此 PWM 低对应短路制动，不是高阻滑行。

独立看门狗 IWDG 在名义 40 kHz LSI 下约 1 秒超时，实际随 LSI 偏差变化；仅完整控制任务完成后喂狗。CPU/中断挂死时看门狗复位，启动时清运动目标、恢复默认 RAM 参数且禁用输出，不恢复旧目标。健康的故障停机循环仍喂狗，保留上述故障位。IWDG 复位不是新增串口故障位。

错误码：0=成功，1=未知命令/保留字段错误，2=范围或选择器错误，3=状态不允许。CRC 错包不应答；应答共用异步发送缓冲区，主循环复用前会等待前一帧发送取数结束，不支持任意速率流水请求。上位机应等待匹配应答后再发下一条。

## 参数表

所有参数均为 uint16。电机参数作用域 1～4；设置时 0 可同时设置四台。读电机参数必须明确指定一台。全部参数写入需停止全部电机；读取单项可以在运行时进行。

| ID | Python 名称 | 范围 | 默认 | 单位 |
|---:|---|---|---:|---|
| 0 | polarity | 0～1 | 0 | 0 正常，1 反向 |
| 1 | max_pwm | 1～1000 | 1000 | PWM 千分比 |
| 2 | max_speed | 1～10000 | 10000 | count/s |
| 3 | cpr | 1～60000 | 1 | 输出轴每圈 A 下降沿计数；1 为默认占位 |
| 4 | kp | 0～1024 | 4 | 实际比例增益 = 值/64 |
| 5 | ki | 0～1024 | 1 | 每 50 ms 的积分增益 = 值/64 |
| 6 | i_limit | 0～1000 | 1000 | 积分贡献的 PWM 千分比限幅 |
| 7 | pwm_accel | 1～1000 | 100 | PWM 千分比/50 ms |
| 8 | pwm_decel | 1～1000 | 100 | PWM 千分比/50 ms |
| 9 | reverse_ms | 50～5000 | 100 | ms，向上取整至控制周期 |
| 10 | stall_pwm | 0～1000 | 300 | PWM 千分比，0 关闭检测 |
| 11 | stall_speed | 0～10000 | 0 | 反馈速度幅度阈值，count/s |
| 12 | stall_ms | 50～10000 | 500 | ms，按控制周期检测 |
| 13 | speed_accel | 1～10000 | 1000 | 速度目标步长，count/s /50 ms |
| 14 | speed_decel | 1～10000 | 1000 | 速度目标步长，count/s /50 ms |
| 128 | timeout_ms | 200～10000 | 1000 | 全局，ms |

参数使用与编译、接线说明见 [README.md](../README.md)。

正常 STM32 V4.3 状态 flags 为 0x40，参数格式为 4、bit0（方向推定）清零；能力位图为 0x073F。A/B/C 路使用输入捕获中断，D 路使用 EXTI，均为 A 下降沿 x1 计数。D 路没有等价的硬件滤波和过捕获指示，B 相也由 ISR 采样，最高可靠计数率及方向判定必须上板验证。
