## 怎么提交

1. 认领 Issue，在 `feature/任务ID-简述` 分支完成修改。
2. 提交目标为 `main` 的 PR，关联 Issue，简述改动和验证结果。
3. 指定技术审核人确认后，由合并负责人合并并关闭任务。

不要求单独编写完整教程。禁止直接推送 main、强制推送、覆盖他人修改或提交密钥。Free 私有仓库的 main 审核规则当前依靠人工执行。
